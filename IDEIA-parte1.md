# Meu primeiro assistente de IA

## O que eu quero
Criar um chat de inteligência artificial que ensine Engenharia de Dados e IA de forma simples. Qualquer pessoa poderá acessar pelo navegador.

## Como quero personalizar
Quero mudar o nome, as cores, a logo, as instruções e os modelos de IA por um arquivo de configuração.

## Qual IA usar
OpenRouter, Anthropic ou OpenAI, com preferência configurável e alternativa caso um provedor falhe.

## Como publicar
Guardar o código no GitHub e publicar no Hugging Face Spaces. O GitHub Actions deve testar tudo antes de publicar automaticamente.

## Segurança
As chaves de API não podem aparecer no código ou no repositório.

## O que não entra agora
Base de documentos, interface profissional, login e histórico salvo ficam para etapas posteriores.

## Como saber que funcionou
Conseguir conversar pelo link público, mudar uma configuração e ver a atualização, e impedir a publicação de configurações incorretas.
